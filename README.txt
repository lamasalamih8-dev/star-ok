STAR OK — متجر ألعاب Full Stack
التشغيل:
1. ثبّت Node.js
2. داخل المجلد: npm install
3. npm start
4. المتجر: http://localhost:3000
5. الإدارة: http://localhost:3000/admin.html

دخول الإدارة الافتراضي:
Email: admin@starok.local
Password: ChangeMe123!

غيّر ADMIN_EMAIL و ADMIN_PASSWORD في متغيرات البيئة قبل النشر العام.
المشروع يستخدم SQLite ويحفظ المنتجات والطلبات محلياً.
للدفع الإلكتروني الحقيقي يلزم ربط بوابة دفع بحساب تاجر، ولشحن PUBG/Free Fire آلياً يلزم API مزود شحن معتمد.
